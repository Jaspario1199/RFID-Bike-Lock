# VELOX rev3f — prototype print-stage STEP files

16 individual solid STEP files, in millimetres, oriented as the build guide suggests and placed at Z=0. File names include order, part, material and revision. No assembly or purchased-component reference is included in the STEP folders.

1. Print the two fit coupons first, in their supplied orientations, and test the actual latch hardware.
2. Print electronics and latch parts after accepting the fits. The printed latch parts are fit/motion prototypes.
3. Frame parts are optional today. The complete clamp hinge uses the deferred A3 housing; these parts alone do not form a complete lock.
4. Print TPU liners after checking the stud press fit; print a small representative fit section first.

A3 spool housing, A4 cover and the metal hinge pin are excluded. Supports still require slicer preview; use the included build guide. Geometry audits passed; real component fit, screw retention and printer calibration remain physical checks.

No printer-settings archive was found in the repository files/history, releases or PR. No profile has been applied and no G-code is included. Do not mix with rev3e or v0.8.3 parts.
