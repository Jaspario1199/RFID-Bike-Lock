# VELOX PCB work

The current compact proposal is [Rev B](revB/README.md): a 90 × 55 mm carrier schematic,
pin map, component selections, placement plan and enclosure proposal.

**Rev B routing and native ERC/DRC are unfinished. It is not a fabrication release.**
The recovered package contains no approved Gerbers or replacement enclosure STEP files.

[Rev A](revA/README.md) remains as the historical 110 × 65 mm routed review prototype.
Its geometry-check results do not validate Rev B or actual charging/solenoid/enclosure behavior.
